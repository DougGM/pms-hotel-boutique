# Recursos Compartidos

`components/` alojará controles genéricos como botones, campos, modales,
tablas, badges y layouts. `lib/` contiene utilidades transversales y `types/`
tipos que no pertenecen a un solo módulo.

Antes de crear un componente, revisar `src/index.css` para reutilizar las
variables, clases y patrones visuales del diseño original de Bolt.
